# 样式规范

## 基本形态

- **unocss 已彻底移除**，禁止再引入原子类；全部用语义 class（扁平命名，不用 scss 嵌套语法糖、不用 BEM）
- 页面样式放同目录 `style.scss`，模板尾部 `<style lang="scss" scoped src="./style.scss"></style>` 引入；公共 mixin 在 `src/styles/common.scss`（`flex_center` / `omit`），vite `additionalData` 全局注入，直接用无需 @use
- 颜色/阴影/圆角一律取 `src/App.vue` 里的 CSS 变量（`--primary`、`--bg-2`、`--text-1`…），**禁止硬编码色值**；这些 tokens 与 `design/common.css` 严格对齐，改色两边同步

## 净额数值配色（红涨绿跌）

- ±分数：正数 `var(--up)`（红 #e64340）、负数 `var(--down)`（绿 #34a35b）——累计输赢、战绩列表、MVP 金额、战绩图画布（画布不认 CSS 变量，用同值硬编码 `#e64340` / `#34a35b`）
- `--win/--lose` 系列只表达「成功/失败」语义（已结算徽章、危险操作卡、确认弹窗警示），不用于净额正负
- 结算方案的转账金额保留红色（`--lose-text`）：语义是「应付」，非带符号净额

## 头像（踩过坑，严格执行）

- **image 元素禁用 `width/height: 100%`**：scoped 下百分比相对自适应父级无法解析 → 头像位塌缩或撑成全宽挤扁文字（home 与 settlement 都踩过）。正确写法：固定尺寸的 `.g-avatar` view 包裹 + 内层 image `width/height: 100%`（父级有定尺寸时可用）
- 全局 `.g-avatar`（App.vue）自带默认背景色 `var(--bg-3)`，防止图片未加载时与页面背景融为一体；规格 xs=48rpx / sm=64rpx / 默认 80rpx
- 头像加载失败兜底统一走 `src/utils/avatar.ts` 的 `useAvatarFallback`（@error → `/static/images/avatar.png`）；`cloud://` fileID 需先转临时链接再渲染（room-detail 的 `avatarDisplaySrc` 模式），新页面加头像不得绕过

## 小程序弹窗

- **不支持 `<transition>`**：常驻渲染 + `.show` class 切换（opacity / visibility / scale / translateY）
- 弹窗含 `input` 且挂在常驻页面（tab 页）上时，关闭后必须最终 `v-if` 卸载 DOM（挂载 → nextTick 加 .show → 关闭动画后延迟卸载）；只靠 visibility 隐藏时真机会重新聚焦隐藏输入框、自动弹键盘（首页完善资料弹窗踩过）
- 二次确认弹窗复用各页面 confirm-dialog 形态：遮罩 fixed + z-index 100，请求进行中按钮 disabled 且遮罩不可关

## 布局

- 间隔用 margin/padding，**禁 `gap` 做纵向间隔的场景不涉及**（本项目为小程序，flex gap 可用；但多按钮换行布局记得 `box-sizing: border-box`，带边框子项的 calc 半宽要留出大于边框的富余，否则 flex-wrap 溢出换行——room-detail entry-btn 踩过）
- 卡片：白底 + `var(--shadow-card)` + `var(--radius-md)`；同数据在不同页面（如结算方案行）保持同一套内边距/间距/头像规格

## design 同步

改了页面 UI，必须同步更新 `design/` 对应静态稿（含 index.html 总览卡的描述文字），保持「设计稿 = 实际页面」。
