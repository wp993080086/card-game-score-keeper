# 项目概述

## 项目是什么

「打牌好友记账」微信小程序：面对面开房打牌、按局记账（谁转谁多少钱）、一键结算出最少转账方案并生成战绩图。

- 单平台交付：**仅微信小程序**（mp-weixin），H5 / App 脚本是 uni 模板遗留，未维护
- 前端：uni-app（Vue 3 组合式 API + TypeScript）+ Vite 5
- 后端：**微信云开发**（云函数 + 云数据库 + 云存储），无自建服务端
- 代码注释与 UI 文案均为中文

## 常用命令

```bash
npm run dev:weixin      # 开发编译（watch），产物 dist/dev/mp-weixin，微信开发者工具导入该目录
npm run build:weixin    # 一次性构建，产物 dist/build/mp-weixin —— 改动后的标准验证手段
```

- `npm run lint` **当前是坏的**（脚本仍用 `--ignore-path`，eslint 9 已移除该参数），存量问题未修；验证代码以 `npm run build:weixin` 编译通过为准，格式由 prettier / 提交钩子兜底
- vite 构建含自定义插件 `cloudfunctionsSyncPlugin`（vite.config.js）：自动把根目录 `cloudfunctions/` 同步进产物目录，dev 下带监听

## 最高优先级硬约束（违反即返工）

1. Vue 3 组合式 API：页面/组件一律 `<script setup lang="ts">`，禁止 Options API（唯一例外：`src/App.vue` 用 Options 写法承载 uni 应用生命周期）
2. 云调用统一走 `src/apis/`（`callCloud`），组件里禁止直接 `wx.cloud.callFunction` / 直接操作云数据库
3. 样式：语义 class + scoped SCSS（unocss 已彻底移除，禁止再引入）；颜色一律取 `src/App.vue` 的 CSS 变量，与 `design/common.css` 严格对齐
4. 净额数值配色：正数红（`--up`）、负数绿（`--down`），国内红涨绿跌习惯；`--win/--lose` 系列仅用于「成功/失败」语义
5. 依赖钉版本：不升级 `@dcloudio/*` 与 vite，不引入新的第三方业务库（经用户确认除外）
6. 不对编译产物（dist/）做外部脚本后处理注入——uni 与微信开发者工具都监听产物目录，外部写文件会触发乒乓死循环；产物调整一律走框架原生机制（如 `src/pages.json`、`src/manifest.json`）
