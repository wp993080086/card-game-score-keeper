# 项目结构

## 顶层

```
├─ AGENTS.md            # agent 规则入口（路由到 .agents/rules/）
├─ .agents/             # rules 规则 + logs 工作日志
├─ src/                 # 小程序前端（uni-app）
├─ cloudfunctions/      # 微信云函数（vite 插件自动同步进 dist 产物）
├─ design/              # 静态 HTML 设计稿（index.html 总览）
├─ docs/                # 云开发方案、UI 设计提示词
├─ scripts/             # 构建辅助（fix-glob-eager.js）
└─ dist/                # 编译产物（dev/build），不入手改
```

## src/ 目录地图

```
src/
├─ App.vue              # 应用生命周期 + wx.cloud.init + 全局样式（设计 tokens CSS 变量、.g-avatar 等）
├─ main.ts
├─ pages.json           # 页面注册与导航栏标题（新增页面必须在此登记）
├─ manifest.json        # appid 等应用配置（mp-weixin.appid 在此）
├─ pages/               # 页面，一页一目录：index.vue + style.scss（页面级样式独立文件）
│  ├─ home/             # 首页：进行中牌局卡片、创建/扫码/输房号进房、房间码解析入口
│  ├─ room/             # 房间（对局中）：成员、快捷语句、邀请弹窗（二维码）
│  ├─ settlement/       # 结算：净额试算、MVP、最少转账方案、确认结算（房主）、退出/解散
│  ├─ room-detail/      # 对局详情：累计输赢、结算方案、已结算后保存/分享战绩图
│  ├─ records/          # 战绩：历史牌局列表与累计统计
│  ├─ flow/             # 流水明细
│  └─ manual/           # 使用手册
├─ apis/                # 云调用层：cloud.ts（callCloud/cloudErrMsg）+ room/game/user.ts
├─ utils/               # 跨页复用：avatar.ts（头像兜底）、poster.ts（战绩图生成/保存/分享）
├─ components/          # 公共组件（SafePageWrapper）
├─ styles/              # common.scss（flex_center/omit mixin，vite 全局注入）+ reset.scss
├─ types/               # 全局类型 commom.d.ts、env.d.ts
└─ static/              # 本地静态资源（含默认头像 avatar.png）
```

## cloudfunctions/ 清单

| 云函数 | 职责 |
|---|---|
| createRoom | 建房、房码生成（qrcode 包生成纯文本普通二维码） |
| joinRoom | 扫码/输码进房（leftAt 软删记录复用→新插一条） |
| leaveRoom | 退房/解散（软删 leftAt） |
| transfer | 记账（game_records append-only，只增不删） |
| settle | 结算落库 + 战绩快照 + 首页小程序码生成 |
| getRoomFlow / getMyGames / getOngoingRoom | 流水、历史战绩、进行中房间查询 |
| checkContent | 内容安全校验 |

## design/ 设计稿

- 静态 HTML（无构建），`design/common.css` 是设计 tokens 源；页面 px 值 ≈ 代码 rpx 的一半
- **改动页面 UI 后必须同步更新对应 design/*.html**，保持设计稿与实际页面对齐（用户明确要求过）

## 新文件放哪

- 页面 → `src/pages/<页面名>/index.vue` + `style.scss`，并在 `src/pages.json` 登记
- 云调用 → `src/apis/` 对应域文件；纯前端工具 → `src/utils/`
- 跨页面公共组件 → `src/components/`
