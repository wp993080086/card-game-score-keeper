# 「打牌好友记账」UI 设计稿提示词（对齐现有需求与页面）

> 用法：整段复制给 AI 设计工具 / 设计师。已按本项目实际页面结构（v2 方案：2 tab + 房间/结算普通页）与业务口径定制。

---

设计一套「打牌好友记账」微信小程序 UI 设计稿，风格：简约轻商务 + 休闲社交，干净通透，不要简陋廉价感，也不要过于花哨的游戏风。产品定位是线下牌局的轻量记分工具：创建房间、好友扫码加入（4 人上限）、按局记分、点头像互相转分、快捷语句聊天、自动结算出最少转账方案、历史战绩回看。页面所有金额一律显示「分」（正整数），全站禁止出现 ¥ 符号、"元"字样及任何收款/支付引导，需保留"本平台不涉及赌博和金钱"的合规声明位。

色彩主调：主色低饱和青蓝（用于按钮、tab 选中、主操作），辅助色浅橙（赢）、浅红（输），背景纯白 + 浅灰分层，文字深灰，减少重色。字体：无衬线圆润字体，层级清晰；卡片圆角适中，柔和阴影，留白充足。

需要输出页面：

1. **首页（tab1）**：顶部用户信息卡（头像 + 昵称 + 编辑入口）；核心操作区「创建房间」（主按钮）与「扫码进房」（次按钮）；「进行中的牌局」卡片（房号、成员头像组、点击回到房间，无进行中对局时显示友好空状态）；底部快捷入口（使用手册、联系客服）。
2. **战绩（tab2）**：历史对局列表，按时间归档（按日期分组），每条显示房号、参与人数、本人输赢分数（赢浅橙 / 输浅红）、可点进查看回放详情；顶部个人累计统计条（总局数、胜率、累计输赢）。
3. **房间页**：顶部浅色公告条"本平台不涉及赌博和金钱，具体请查看使用手册"；横向成员头像条（最多 4 人 + 1 个"邀请"虚线占位，点击邀请弹出房间二维码弹窗：居中大码、房号、转发按钮）；中部消息流（混合系统消息/记分动态"A 向 B 支付 N 分"/成员快捷语句聊天，自己消息右侧气泡主色，他人消息左侧带头像）；底部操作栏「记一局」主按钮 + 「快捷语句」按钮（弹出 10 条预置语句面板，如"快点吧，我等到花儿都谢了"，点选即发送）；点击成员头像弹出向其转分面板（输入正整数分数 + 确认）。
4. **记一局弹层**：半屏弹层，列出在场 4 名成员，每行头像 + 昵称 + 一键加减分步进器（+1/-1 快捷与数字输入），底部"本局小计校验和为 0 提示"与确认按钮。
5. **结算页**：顶部 MVP 区（皇冠头像 + 昵称 + 最高收益 N 分，浅橙渐变背景）；「结算方案」卡片列出最少转账笔数方案（A → B N 分，箭头连接，金额用输赢色）；功能区 2×2 网格（排行榜、流水明细、使用手册、退出房间，退出为浅红警示样式）；底部「分享战绩图」按钮（生成含成员净额排名 + MVP + 小程序码的图片，可保存相册）。
6. **对局详情页（从战绩进入）**：该局每局记分明细时间线、每人累计输赢统计条形图、当时的转账结算方案只读回看。
7. **使用手册页**：分步图文说明（快速入门三步、如何记分、如何结算），轻量卡片排版。

交互细节：表单极简，一键加减分数；结算页输赢金额用浅橙/浅红高亮；所有空状态（无进行中对局、无历史战绩、房间已解散）配友好插画式提示；房间页消息流区分系统灰字 / 聊天气泡两种质感；转分、退出房间、解散房间均需二次确认弹窗。

输出格式：移动端小程序页面，竖屏 375px 宽度，每个页面标注模块名称，不要多余装饰，工具属性优先，保留精致细节。
